# Kostplaneraren 🥗
Planera måltider med näringsdata från Livsmedelsverkets öppna API.

🔗 Live: https://kostplaneraren.se

---

## Om projektet

**Kostplaneraren** är ett privat utvecklingsprojekt byggt för att göra
livsmedelsdata mer tillgänglig och användbar i vardagen.

Projektet hämtar näringsvärden direkt från **Livsmedelsverkets öppna livsmedelsdatabas**
och presenterar dem i ett enkelt, snabbt och mobilanpassat gränssnitt.

Fokus har legat på:
- tydlighet
- prestanda
- låg tröskel för användning  
utan onödig komplexitet.

---

## Funktioner

- 🔍 Sök bland livsmedel
- 📊 Visa näringsvärden per livsmedel
- 🧮 Summering av valda livsmedel
- 📱 Responsiv design (fungerar bra på mobil)
- ⚡ Snabb klient utan backend-beroenden

---

## Teknikstack

- **HTML / CSS / JavaScript**
- **Livsmedelsverkets öppna API**
- Ingen server-side backend
- Ingen inloggning eller lagring av användardata

Projektet är medvetet byggt som en **lättviktig frontend-lösning**.

---

## Datakälla

Näringsdata kommer från:

**Livsmedelsverkets Livsmedelsdatabas**  
Version: *2025-06-09*

> Denna webbplats är ett privat projekt och inte en officiell tjänst från Livsmedelsverket.

---

## Syfte & bakgrund

Kostplaneraren skapades som:
- ett praktiskt verktyg
- ett tekniskt experiment
- ett exempel på hur öppen data kan användas på ett meningsfullt sätt

Projektet är också en del av mitt större samlingsnav **Hilden Media – Teknik med själ**.
